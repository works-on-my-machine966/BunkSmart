# 🎓 BunkSmart Analytics v2.4

> **Smart Attendance Shortage Prevention Dashboard**

BunkSmart Analytics helps college students monitor, simulate, and optimize their attendance to prevent shortages before they happen. Built with React and Vite.

---

## ✨ Features

- **📊 Live Scorecard:** Real-time visibility into overall and subject-level attendance percentages.
- **⚡ Bunk & Recovery Simulator:** 
  - **Safe Regime ($P \ge T$):** Calculates the exact number of classes you can safely skip.
  - **Deficit Regime ($P < T$):** Calculates consecutive classes needed to recover back to target status.
- **📚 Academic Matrix:** Comprehensive module breakdown tracking course priorities and safety margins.
- **💡 Smart Insights:** Context-aware recommendations based on attendance rules ($75\%$, $80\%$, $85\%$).

---

## 🛠️ Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
